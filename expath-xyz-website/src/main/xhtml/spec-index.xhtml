EXPath Community Group - Specifications

This website presents the outputs of the W3C EXPath Community Group.

The purpose of the EXPath Community Group is to collaboratively define standards for XPDLs (XPath Derived Languages). Many of the specifications produced define function libraries that enhance and extend the standard function libraries, thus allowing users of XPDLs (e.g. XQuery, XSLT, XProc, XForms, XSpec, etc) to perform advanced tasks that were not previously envisaged.
